# 产品开发计划（需求总览 + 优先级）

本文档只描述“要做出什么能力”和“如何验证功能达标”，不展开具体技术实现。  
详细任务卡拆分在 `docs/product-plan/` 目录下，按阶段维护。

## 1. 产品目标

- 当前形态：多模态调用 + 基础对话
- 目标形态：可完成目标任务的 AI 助手（具备 Agent 执行能力）
- 关键提升：从“回答问题”升级为“分步完成并交付结果”

## 2. 阶段优先级

- `P0`：打通 Agent 最小闭环（必须优先）
- `P1`：提升回答质量与可追溯性（来源、文档问答、稳定性）
- `P2`：增强复杂任务处理能力（中断恢复、记忆、模板交付）
- `P3`：产品化与规模化（路由、监控、自动化门禁）

## 3. 依赖关系

- `Agent 执行` 依赖 `工具调用框架`
- `联网问答质量` 依赖 `搜索/抓取/引用链路`
- `文档问答` 依赖 `RAG 检索能力`
- `长期记忆` 依赖 `会话摘要与持久化结构`
- `成本优化` 依赖 `指标采集与可观测性`

## 5. 里程碑建议

- `v0.2.x`：P0 完成，具备可演示的 Agent MVP
- `v0.3.x`：P1 完成，联网与文档问答质量明显提升
- `v0.4.x`：P2 完成，支持复杂任务闭环
- `v1.0.0`：P3 关键项完成，进入稳定发布节奏
