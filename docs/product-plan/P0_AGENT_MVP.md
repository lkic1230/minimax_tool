# P0 任务卡：Agent MVP（修订版）

## 阶段目标

**核心转变**：从"用户手动操作"升级为"AI 自动驱动工作流"

- 用户描述目标 → AI 自动分析 → 任务拆解 → 工具调用 → 结果返回
- 完成"AI 对话 + 自动执行"的最小闭环
- 用户只需描述任务，其他交给 AI

---

## 架构设计（三层）

```
┌─────────────────────────────────────────────────────────┐
│  意图解析层    │  理解用户输入，判断是否需要工具        │
├─────────────────────────────────────────────────────────┤
│  任务规划层    │  自动拆解任务，确定工具调用顺序        │
├─────────────────────────────────────────────────────────┤
│  工具执行层    │  执行工具，返回结果给 AI               │
└─────────────────────────────────────────────────────────┘
```

---

## 需求清单（AI 驱动模式）

### 1. 对话式任务输入

- [ ] `P0-RQ-001` **自然语言任务描述**：用户输入任务目标（如"调研Python最新动态"）
- [ ] `P0-RQ-002` **AI 任务确认**：AI 理解任务后，确认任务范围和预期输出
- [ ] `P0-RQ-003` **自动拆解展示**：AI 显示任务拆解方案（用户可确认或调整）

### 2. AI 驱动执行循环

- [ ] `P0-RQ-004` **自动工具决策**：AI 自主判断需要调用哪些工具
- [ ] `P0-RQ-005` **执行循环**：AI 自动执行步骤，结果返回给 AI，AI 决定下一步
- [ ] `P0-RQ-006` **自动结束判断**：AI 判断任务完成并输出结果

### 3. 工具能力

- [ ] `P0-RQ-007` **联网搜索**：支持搜索并返回来源链接
- [ ] `P0-RQ-008` **网页抓取**：支持抓取网页正文
- [ ] `P0-RQ-009` **文件操作**：支持受控目录的文件读写

### 4. 状态与进度

- [ ] `P0-RQ-010` **实时状态展示**：显示当前执行阶段、进度百分比
- [ ] `P0-RQ-011` **步骤详情**：展示每一步的名称、状态、耗时
- [ ] `P0-RQ-012` **当前步骤高亮**：执行中的步骤有明确标识

### 5. 交互控制

- [ ] `P0-RQ-013` **用户确认点**：关键步骤执行前可选择确认或中断
- [ ] `P0-RQ-014` **用户中断**：支持手动停止任务
- [ ] `P0-RQ-015` **结果展示**：最终结果带来源引用、结构化摘要

---

## 核心差异（对比旧版）

| 旧版（手动模式） | 新版（AI 驱动） |
|----------------|----------------|
| 用户手动创建任务 | 用户描述目标，AI 自动创建 |
| 用户点击执行 | AI 自动循环执行 |
| 用户查看步骤 | AI 实时推送状态 |
| 手动触发下一步 | AI 自动判断完成 |
