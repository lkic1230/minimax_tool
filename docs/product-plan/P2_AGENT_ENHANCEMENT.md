# P2 任务卡：Agent 能力增强

## 阶段目标

- 让 Agent 支持中长流程任务，具备中断恢复与个性化记忆能力。
- 将结果输出升级为可直接交付的结构化产物。

## 需求清单（功能视角）

- [ ] `P2-RQ-001` 计划生成：接到任务后生成可读的多步骤计划。
- [ ] `P2-RQ-002` 计划调整：执行过程中允许更新后续步骤计划。
- [ ] `P2-RQ-003` 步骤依赖：支持前一步失败时暂停后续依赖步骤。
- [ ] `P2-RQ-004` 阶段结果：每个阶段都产出中间结果摘要。
- [ ] `P2-RQ-005` 暂停机制：执行中支持“暂停任务”并保留现场。
- [ ] `P2-RQ-006` 恢复机制：重启应用后可选择恢复未完成任务。
- [ ] `P2-RQ-007` 恢复校验：恢复前展示上次进度与最后一步状态。
- [ ] `P2-RQ-008` 记忆查看：用户可查看已保存的偏好与项目背景。
- [ ] `P2-RQ-009` 记忆编辑：支持修改错误或过期记忆。
- [ ] `P2-RQ-010` 记忆删除：支持单条删除与全部清理。
- [ ] `P2-RQ-011` 记忆开关：用户可按任务选择是否启用记忆。
- [ ] `P2-RQ-012` 白名单总开关：可统一开关工具调用能力。
- [ ] `P2-RQ-013` 白名单细粒度：可按工具类型单独启停。
- [ ] `P2-RQ-014` 模板A：调研报告模板输出。
- [ ] `P2-RQ-015` 模板B：方案对比模板输出。
- [ ] `P2-RQ-016` 模板C：执行清单模板输出。
- [ ] `P2-RQ-017` 模板预览：导出前可预览模板填充结果。

## 用户体验要求

- 中途关闭应用后，用户可无缝继续任务。
- 记忆可控，用户知道“记住了什么”，并可手动清理。
- 输出结果能直接用于工作交付，而非仅聊天文本。

## 建议开发顺序（Wave）

- `Wave 1（计划与执行编排）`：`P2-RQ-001~004`
- `Wave 2（中断恢复）`：`P2-RQ-005~007`
- `Wave 3（记忆能力）`：`P2-RQ-008~011`
- `Wave 4（权限控制）`：`P2-RQ-012~013`
- `Wave 5（交付模板）`：`P2-RQ-014~017`

## 测试点（验收）

- [ ] `P2-TC-001` 多步骤执行时，当前步骤与后续计划变化可见且一致。
- [ ] `P2-TC-002` 模拟前序失败后，依赖步骤不会被误执行。
- [ ] `P2-TC-003` 执行中暂停后恢复，状态、日志、上下文保持连续。
- [ ] `P2-TC-004` 重启应用后恢复任务，最后步骤信息与中断前一致。
- [ ] `P2-TC-005` 记忆新增、编辑、删除后，对话行为按预期变化。
- [ ] `P2-TC-006` 关闭记忆开关后，本轮任务不读取历史记忆。
- [ ] `P2-TC-007` 白名单关闭某工具后，该工具调用请求被明确拦截。
- [ ] `P2-TC-008` 三种模板输出字段完整，导出内容可直接使用。
- [ ] `P2-TC-009` 模板预览与最终导出结果一致。
